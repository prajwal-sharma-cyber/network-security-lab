# Network Threat Model

## Assets
- User endpoints
- Servers
- Network infrastructure
- Administrative accounts
- Business data

## Threats and Controls

| Threat | Potential Impact | Control |
|---|---|---|
| Unauthorised access | High | MFA + least privilege |
| Lateral movement | High | VLAN segmentation |
| Reconnaissance | Medium | Monitoring + firewall rules |
| Traffic interception | High | TLS/secure protocols |
| Brute force | High | MFA + rate limiting |
